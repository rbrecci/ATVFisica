# 🔬 A Viagem pelo Mundo dos Átomos

Projeto desenvolvido para uma atividade de Física, com o objetivo de apresentar conteúdos relacionados ao **mundo dos átomos** de forma visual e interativa.

## 📚 Sobre o projeto

O projeto apresenta informações e conteúdos relacionados à Física e aos átomos através de uma página web.

## 🛠️ Tecnologias utilizadas

* HTML
* CSS
* JavaScript

## 📁 Estrutura

```text
ATVFisica/
├── assets/
├── paginas/
├── A-Viagem-pelo-Mundo-dos-Atomos.pdf
└── index.html
```

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.
